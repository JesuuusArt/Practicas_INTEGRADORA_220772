## Descripción

En esta práctica se utiliza el agente Archify para generar un Business Model Canvas interactivo para **Spotify**, una herramienta multiplataforma de uso cotidiano. El proceso incluye la redacción del prompt, la revisión del modelo obtenido y la iteración del prompt para mejorar el resultado, documentando todo con buenas prácticas.

## Objetivo

El estudiante realizará un prompt para solicitar el modelo Business Canvas para una herramienta multiplataforma que exista o use en su vida cotidiana.

## Actividades

- Elegir la Aplicación Multiplataforma
- Estructurar el Prompt para la generación del Modelo usando Archify
- Revisar el Modelo Obtenido
- Editar el prompt para mejorar el resultado obtenido
- Documentar y agregar al repositorio en base a los requisitos solicitados (buenas prácticas)

## Tecnologías utilizadas

- Archify (generación y validación del modelo)
- HTML, CSS y JavaScript (diagrama interactivo)
- Node.js (build reproducible `tools/build-canvas.mjs`)
- Git y GitHub Pages (versionado y publicación)

## Conclusión

La práctica permitió consolidar el uso de Archify mediante un ciclo de trabajo reproducible: redactar un prompt, generar el modelo, revisarlo críticamente y mejorarlo iterativamente. Además, se documentó el proceso aplicando buenas prácticas de organización y versionado en el repositorio.
